# デザイン設計書（白ベース × 緑アクセント、モバイル優先）

## 目的と基本方針
- 白を基調に、緑をアクセントとしたクリーンで明快な UI。
- モバイル優先で設計し、デスクトップでは余白・最大幅のみ拡張。
- 全ページ共通の左右余白を確保し、中央寄せをデフォルトとする。

## カラーパレット（CSS Variables）
```css
:root {
  --bg: #ffffff;
  --surface: #f6f9f7;
  --primary: #2fb36f;
  --primary-strong: #24945b;
  --text: #1b1f24;
  --muted: #6b7280;
  --border: #e2e8f0;
  --error: #e53935;
  --info: #2563eb;
  --success: #2fb36f;
}
```
- アクセントは緑系 1〜2 トーンに絞り、リンクも同系色で統一。
- シェーディングが必要な場合は `primary` を 5–10% 暗くした色を使用。

## タイポグラフィ
- 見出し: Plus Jakarta Sans（太めウェイト）。
- 本文: Noto Sans JP（通常ウェイト）。本文行間 1.6、モバイルは 16px 基準、デスクトップは 18px。
- 文字間はやや広め（例: 0.02em）を推奨。

## レイアウト・余白・センタリング
```css
:root {
  --page-max-width: 1200px;
  --page-padding: 16px;
}
@media (min-width: 960px) {
  :root { --page-padding: 24px; }
}
.page-shell {
  margin: 0 auto;
  max-width: var(--page-max-width);
  padding: 0 var(--page-padding);
}
.page-shell--wide { max-width: 1440px; } /* 必要に応じて拡張用 */
```
- 全ページのラッパーを `.page-shell` で包み、左右余白と中央寄せを強制。
- ブレイクポイント目安: 600px（タブレット開始）、960px（デスクトップ開始）。

## スペーシング / 角丸 / 影
- スペーシングスケール: 4 / 8 / 12 / 16 / 24 / 32 を基本。
- 角丸: カード・入力 12px、ボタンは 12px またはピル型（999px）で統一。
- 影: 基本 `0 10px 30px rgba(0,0,0,0.08)`、ホバー時にわずかに強める。

## フォーム & ボタン
- ラベルは常時表示、入力は枠線 `var(--border)`、フォーカスで `var(--primary)` に。
- フォーカスリング例: `outline: 2px solid rgba(47,179,111,0.35); outline-offset: 2px;`
- ボタン: フル幅をデフォルト、プライマリは `--primary` / ホバーで `--primary-strong`、無効時は不透明度 0.5。
- 入力間隔は 12–16px、タップターゲット高さは 44px 以上。

## 状態・フィードバック
- エラー: テキストとアウトラインを `--error` に揃える。
- 成功: 緑系トースト、情報: グレー/ブルー系（`--info`）。
- エラーメッセージは入力直下に表示し、スクリーンリーダー向けに `aria-live="polite"` を推奨。

## コンポーネントのスタイル方針（ログイン画面想定）
- レイアウト: 中央寄せカード（幅 420–480px）、背景は `--bg`、カード背景に `--surface` を使用。
- 構成: ロゴ（任意）→ 見出し → サブテキスト → フォーム（メール/パスワード）→ アクション行（例: パスワード表示切替、リンク）。
- モバイル: 1 カラム、左右 16px のパディングでビュー内に収める。デスクトップは上下余白を 64px 以上とり、カード幅を制限。
- アニメーション: ページロード時にフェード＆軽い上方向のモーション（例: `translateY(8px)`, `opacity` 0→1, 250ms）を許容。

## アクセシビリティ
- ラベルは可視状態で関連付け（`<label for=...>`）。プレースホルダは補助的に使用。
- コントラストは WCAG AA を満たす配色にする（緑アクセント上の白テキストは十分なコントラストあり）。
- フォーカスリングを必ず表示、キーボード操作で完結できることを確認。

## 運用メモ
- ページ全体の左右余白は `.page-shell` で統一し、例外（全幅ヒーロー等）は修飾クラスで管理。
- 新規ページはまずモバイルの 1 カラムで構成し、600px/960px での横幅拡張のみで成立する構造を基本とする。
